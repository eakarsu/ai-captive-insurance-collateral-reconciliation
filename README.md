# Captive Insurance Collateral Reconciliation

Reduce trapped capital by independently calculating collateral requirements and supporting timely release requests.

**Primary buyer:** Captives, risk managers, and fronting carriers. **Evidence:** fronting agreements, loss runs, reserves, IBNR, paid losses, premiums, security requirements, letters of credit, trusts, and releases.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Fronting agreement library
- Program year registry
- Loss run ingestion
- Case reserve validation
- IBNR methodology
- Paid loss credit
- Premium offset control
- Collateral formula calculation
- Instrument inventory
- Letter-of-credit fee audit
- Trust asset reconciliation
- Release opportunity detection
- Fronting carrier request
- Accounting close reconciliation
- Program capital analytics

Run `./start.sh`, then open <http://127.0.0.1:4665>. API: `5665`.
